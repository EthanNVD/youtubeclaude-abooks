# Project: Abooks — Vietnamese book-review scripts

- This repo writes Vietnamese audiobook/book-review scripts in the Abooks style (philosophy, spirituality: Krishnamurti, Osho, Buddhism)
  with the skill `abooks-writer` (`.claude/skills/abooks-writer/SKILL.md`): rewrite an existing script or subtitle, research and write a new one,
  or propose 5 new topics.
- Talk to the user in Vietnamese.
- Working folders: `abooks/<ten-ngan-khong-dau>/` (scripts, work), `krishnamurti/` (older Krishnamurti scripts and research).
  Scripts, transcripts and sources stay local and are NOT committed unless the user asks (they are in .gitignore).
- This repo has nothing to do with video making (that is `youtubeclaude-video`). Never publish anything.
